- **Technical discussion and collaboration.** Email the maintainer to discuss the architecture, single-workstation inference, Windows or CUDA optimization, or joint benchmarking. [ntcubic@gmail.com](mailto:ntcubic@gmail.com)

GitHub issues are public. Use email for discussions involving customer data or unpublished implementation details. [Maintainer's GitHub profile](https://github.com/nt-cubic)
